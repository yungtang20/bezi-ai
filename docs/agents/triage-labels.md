# Matt triage vocabulary

| Role | Label name | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | 待判斷 |
| Needs information | `needs-info` | 待補資訊 |
| Ready for agent | `ready-for-agent` | 可執行、可驗收 |
| Ready for human | `ready-for-human` | 須人類執行的限制 |
| Won't fix | `wontfix` | 不予實作 |

這是規範使用的**建議標籤名稱**，不是宣稱 GitHub label 已全部建好。若 connector 無法建立 label，保持 Issue 的 `Status` 文字並避免阻擋實作。#50 需要使用者最後明確核准。
