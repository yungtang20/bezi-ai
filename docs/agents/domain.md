# Domain Docs / Agent Consumer Rules

- Single-context: `GLOSSARY.md`；重要不可逆的領域/架構決定位於 `docs/adr/`。
- 讀程式前先核對 `AGENTS.md`、`GLOSSARY.md`、相關 ADR 與最新 main/PR HEAD commit；舊 `.opencode/memory/` 文件僅作歷史背景。
- 先使用原始教材、已核對的四柱案例或實際 API 回應作為證據；`LLM_WIKI.md` 與測試不是原始教材替身。

- 不得把 Bezi 命理領域放進司法/法律產品或其他專案。
