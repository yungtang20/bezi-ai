# 徐玉蘭格局引擎：講義優先修正／驗證邊界

此分支修正的是**已由教材與官方網頁單盤追蹤相互支持的子集**，並非聲稱掌握徐玉蘭的完整後端程式。

## 來源階層

1. 使用者提供《定格局》原始講義：日干不列入七字、年干5／年支20／月干5／月支35／日支20／時干5／時支10；三合與半合僅取有利日主之加分。
2. 課堂逐字稿 `1-2-2 [19:26–19:45]`：酉丑屬半合金；`1-3 [36:55–37:54]`：卯未半合木讓原本未支 0→20，案中40→60（原音未獨立校聽）。
3. 使用者保存的 `https://masterhsu.sat.cool/strength/explain` 12 張去重官方網站截圖：`甲子／丁丑／癸酉／癸丑` 七字45，步驟5～7不變，步驟8月丑0→35、時丑0→10、日酉仍20，步驟9總分90、從強格。

不把完整課程字幕、截圖或個人出生資料存入公開儲存庫。

## 實作範圍

- `calculateHandoutStrength`：不計日干，保留各位置的 `beforeElement / afterElement / beforePoints / afterPoints`。
- 半合：目前僅實作以三合中央支為核心的**相鄰兩支**，同一支可與不同相鄰支形成相同有效元素，但每個柱位只取一次分數。
- **證據閘門**：只有官網完整截圖確認的 `甲子／丁丑／癸酉／癸丑` 可將45→90標示為該站已觀察的完整輸出；其他相似半合只展示逐位置「候選覆寫」，`status=REVIEW_REQUIRED`、`score=null`、`delta=null`，不得直接定格局。
- `determinePattern` 僅對已觀察的網站單盤採用新計算；其餘命盤繼續舊路徑，並將 `handoutTrace` 及「半合覆寫未經跨盤驗證／舊引擎暫算」附在結果中，**不表示舊路徑其餘固定加減分已驗證**。
- 80以上可進入從強分數區間；正式格局仍須另行檢核老師使用的成格條件與流年體感定盤。

## 缺口與後續要求

- 尚未取得經授權的網站後端原始碼與部署版本對照，因此無法聲稱全站算法等價。
- 尚需正確處理三合完整局、三會、暗拱、刑沖拆合、六合／合絆對半合優先序的互動。
- 舊版 `determinePattern` 仍包含藏干30%、透干+3等尚未獲得原始來源充分確認的加分假設；本PR只處理已知最關鍵問題，不能因單盤90分通過就將其它公式核定。
- `1-3` 的完整課堂四柱與原音須核對後才能做一筆完整「40→60」正式回歸；目前有合成單元測試僅驗證「未支20分改列」。
- 真正未曝光案例盲測仍0筆；不得把此前的示範案例充當盲測。

## 驗收

`npm run lint`、`npm test`、`npm run build`，以及新增的 `tests/unit/handoutStrength.test.ts`。CI 工作流結果若未取得，必須明記 `NOT_VERIFIED`。

本 PR 適合先合入已驗證的低風險子集，後續再用授權後端與更多不同命盤完善全套規則。
